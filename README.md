# আমার সিরাজদিখান (Amar Sirajdikhan) - উপজেলা স্মার্ট সেবা ও তথ্য পোর্টাল

**আমার সিরাজদিখান** হলো একটি আধুনিক, ডিজিটাল ও সমন্বিত উপজেলা পর্যায়ের ওয়েব অ্যাপ্লিকেশন। সিরাজদিখান উপজেলার সকল নাগরিক সেবা, জরুরী সেবা, স্বাস্থ্য সেবা, রক্তদান ব্যবস্থাপনা, বিভিন্ন পেশাজীবী ও কারিগরদের সাথে যোগাযোগের তথ্য এক ছাদের নিচে পৌঁছে দেয়াই এই প্ল্যাটফর্মের মূল লক্ষ্য।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **জরুরী হটলাইন ও সরকারি দপ্তর**:
   - ইউএনও অফিস, মডেল থানা, ফায়ার সার্ভিস, পল্লী বিদ্যুৎ, হাসপাতাল জরুরী বিভাগ এবং অন্যান্য সরকারি কর্মকর্তাদের ফোন নম্বর ও ইমেইল।
2. **স্বাস্থ্যসেবা কেন্দ্র ও পেশাজীবী**:
   - হাসপাতাল, ক্লিনিক, ডায়াগনস্টিক সেন্টার, বিশেষজ্ঞ ডাক্তার, হোমিও ডাক্তার, পশু ডাক্তার, উপজেলা ডাক্তার, অ্যাম্বুলেন্স সেবা ও ২৪/৭ ফার্মেসী।
3. **স্মার্ট ব্লাড ব্যাংক ও ডোনার নেটওয়ার্ক**:
   - রক্তদাতা রেজিস্ট্রেশন, ব্লাড গ্রুপ অনুযায়ী ডোনার ফিল্টার, তাৎক্ষণিক ব্লাড রিকুয়েস্ট পোস্ট এবং স্থানীয় রক্তদান সংগঠনসমূহের তালিকা।
4. **মেস্ত্রী ও টেকনিশিয়ান সার্ভিস**:
   - ইলেকট্রিক, স্যানিটারি, টাইলস, কাঠের কাজ, অটোরিক্সা মেকানিক, পেইন্ট, টায়ার ও মোটর মেকানিকসহ সকল অভিজ্ঞ কারিগরের কন্টাক্ট ডিরেক্টরি।
5. **নাগরিক ও দৈনন্দিন সেবাসমূহ**:
   - রেন্ট-এ-কার, বাইক রাইড শেয়ার, রেস্টুরেন্ট ও অনলাইন ফুড অর্ডার, বাসা বদল সার্ভিস, কাজী অফিস, দলিল লেখক, জমি সার্ভেয়ার (আমিন), বিউটি পার্লার, কুরিয়ার সার্ভিস, পোস্ট অফিস ইত্যাদি।
6. **শিক্ষা ও সমাজ**:
   - স্কুল, কলেজ, মাদ্রাসা, কোচিং সেন্টার, টিউশন সেবা, অনলাইন সেবা সেন্টার, বই লাইব্রেরি ও স্বেচ্ছাসেবক সংগঠন।
7. **অ্যাডমিন প্যানেল (Admin Panel)**:
   - পাসওয়ার্ড সংরক্ষিত সিকিউর অ্যাডমিন ড্যাশবোর্ড।
   - যেকোনো ক্যাটাগরি, ডাটা এন্ট্রি লাইভ যুক্ত (Add), সম্পাদনা (Edit), ও মুছে ফেলা (Delete) এর পূর্ণ নিয়ন্ত্রণ।
   - পেন্ডিং ব্লাড রিকুয়েস্ট ও ডোনার ভেরিফিকেশন সুবিধা।

## 📁 প্রজেক্ট স্ট্রাকচার (Project Structure)

```text
amar_sirajdikhan/
├── index.html          # প্রধান ওয়েব পেজ (একক পেজ অ্যাপ্লিকেশন UI Structure)
├── css/
│   └── style.css       # প্রাইম ডিজাইন সিস্টেম, থিম ডার্ক/লাইট মোড, গ্রিড, এনিমেশন
├── js/
│   ├── app.js          # ফ্রন্টএন্ড লজিক, ক্যাটাগরি রেন্ডারিং, ফিল্টারিং, সার্চ, মডাল হ্যান্ডলিং
│   ├── data.js         # প্রাথমিক রিয়েলিস্টিক ডাটা সেট (৫০+ ক্যাটাগরি ও এন্ট্রি)
│   └── admin.js        # অ্যাডমিন ড্যাশবোর্ড লজিক, CRUD অপারেশন, লোকালস্টোরেজ সিংকিং
├── APP_FLOW.md         # অ্যাপ্লিকেশনের বিস্তারিত ইউজার ও অ্যাডমিন নেভিগেশন ফ্লো
└── README.md           # প্রজেক্ট ডকুমেন্টেশন
```

## 🛠 প্রযুক্তি ও টেকনোলজি স্ট্যাক (Tech Stack)

- **Language & Core**: HTML5, CSS3, JavaScript (ES6 Modules/Vanilla JS)
- **Design & Icons**: Vanilla CSS Dynamic Glassmorphism, Google Fonts (Hind Siliguri / Inter), FontAwesome Icons
- **Data Storage**: Dynamic LocalStorage Database with Prefilled Seed Data (Can be linked to Firebase/REST API)
- **Responsiveness**: Mobile-first Responsive UI with Bottom Navigation Bar & Drawer Menu

## 🚀 কীভাবে রান করবেন (How to Run)

1. প্রজেক্ট ফোল্ডারটি ডাউনলোড অথবা ক্লোন করুন।
2. `index.html` ফাইলটি যেকোনো ব্রাউজারে (Chrome, Edge, Firefox, Safari) ওপেন করুন।
3. অথবা আপনার লোকাল ডেভেলপমেন্ট এনভায়রনমেন্টে Live Server দিয়ে রান করুন:
   ```bash
   npx serve .
   ```
